# 🎮 Jogo Desbravadores

Um jogo educativo desenvolvido para os Desbravadores, com o objetivo de proporcionar uma experiência interativa e divertida enquanto trabalha conhecimentos relacionados ao clube.

## 🕹️ Sobre o projeto

Este projeto foi desenvolvido como uma aplicação web utilizando tecnologias fundamentais do desenvolvimento Front-end.

O jogo foi criado para ser executado diretamente no navegador, sem necessidade de instalação.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivos do projeto

- Praticar desenvolvimento Front-end
- Trabalhar estruturação de páginas com HTML
- Desenvolver estilização com CSS
- Utilizar JavaScript para criar interações
- Publicar uma aplicação web utilizando GitHub Pages

## 🌐 Jogue online

👉 **[Clique aqui para jogar](https://milenasilvadev.github.io/game-desbravadores/)**

## 🚀 Como executar

Você pode jogar diretamente pelo navegador através do GitHub Pages.

Para executar localmente:

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
